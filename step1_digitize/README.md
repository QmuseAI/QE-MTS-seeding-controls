## 提取方法与精度

- **Fig.5 是矢量图。** 直接读取 PDF 里的绘图指令，中位数精确到约 1e-3 dex，没有数字化误差。
- **Fig.2 是嵌入的 856×599 JPEG。**
  - 纵轴用 17 个刻度标定（1e6 主刻度，2e5–9e6 次刻度），残差 2.6e-4 dex；1 像素 = 0.003 dex。
  - 黑色标记取像素范围的中心。N=35 MTS 的标记被虚线遮住一部分，已在 csv 里标出（partial=1）。
- **三项交叉验证都通过：**
  - 用提取的 Q0.50 做 27–37 拟合，得到 κ = 1.236 / 1.366，原文为 1.24 / 1.37；R² = 0.871 / 0.864，落在原文给的区间内。
  - 用同一标定去拟合原图里的两条虚线，得到 κ = 1.240 / 1.367。
  - Fig.2 算出的 D 与 Fig.5 中位数的差别 ≤ 0.01（N=27、28 除外，差 0.03–0.06，因为 Fig.5 是对 bootstrap 的比值取中位数，不是中位数之比）。

## 结果

**1. 斜率差在统计上是显著的，不是统计假象。**
- 配对拟合（每个 N 只有一个 LABS 实例，它的难度涨落在 D 中抵消）：27–37 窗口上 κ_QE/κ_MTS = 0.910 [0.876, 0.945]，p = 3e-4。
- 去掉 MTS 明显偏快的 N=28、30、31 后：κ = 1.207 对 1.315，比值 0.921 [0.896, 0.946]，仍然显著。
- 所以 ANALYSIS.md 2.3 节"用 R² 反推得 p≈0.06"的论点应当**删除**。

**2. 单独拟合的 κ 对窗口很敏感，原文的 CI 明显偏窄。**
- κ_MTS 在 1.22（33–37）到 1.51（30–37）之间，κ_QE 在 1.17 到 1.33 之间。
- 加上逐 N 失拟后，27–37 的 OLS 区间是 QE [1.16, 1.31]、MTS [1.24, 1.50]；原文的 bootstrap 区间是 [1.23, 1.25] 和 [1.36, 1.37]。
- 但配对比值在所有包含 N≥33 的窗口里都小于 1（33–37 上为 0.960 [0.943, 0.978]）。只有 27–31 窗口方向相反（1.05）。

**3. D(N) 的形状：先有一个台阶，之后继续下降但在减速。**
- N=27–31 时 D ≈ 0.35–0.45，N=32 降到 0.25，N=33–37 依次为 0.13、0.11、0.08、0.07、0.06。
- 两档阶跃模型的 AICc 最低（断点在 33），但断点是事后挑的，只能作为描述。
- **更正之前的判断：** N=33–37 不是平台。这一段 D 的斜率是 −0.018/N，95% CI [−0.026, −0.010]，仍然显著下降。

**4. 关键：现有数据无法区分两种前景，但在 N≈40–45 可以区分。**
- 用 N=33–37 拟合：
  - 线性模型 RMS 0.006，D 在 N≈40 处到 0；
  - 几何衰减模型（加性开销型）RMS 0.0035，D 永远大于 0。
- 两者在 N≈42 相差 ≥0.05 dex，在 N≈45 相差约 0.1 dex。
- 按原文自己的 Q0.50 直线，**中位数层面的交叉应该在 N≈38–40 就出现**；原文的 N≈47 用的是更保守的 Q0.95 对 Q0.05 判据。

**5. Fig.5 的下尾随 N 变重。** KDE 主体中 D<0 的比例从 N≤31 时的 0，增加到 N=37 时的约 0.29；最小值低到 −1.2。这对应原文说的"部分 replicate 特别快"，很可能是种子恰好离最优解很近的那些 replicate。

## 对后续计划的影响

- **只靠原文数据驳不倒原文。** 斜率差在统计上是真的，D 在 N≤37 也确实在下降。
- 审计必须靠自己的经典对照：
  - A1/A2 是否复现同样的 D(N) 形状，包括 31→33 的台阶、之后的减速、越来越重的下尾；
  - 再把 A0/A2 跑到 N≈40–45，看 D_A2 是否穿过 0。
- 可以给出一个很具体的预测：如果斜率变平只是协议造成的，D_A2 = log10(TTS_A2/TTS_A0) 在 N=40–45 应该始终大于 0，并呈几何衰减；但把同样的线性外推用在 N≤37 的 A2 数据上，也会"预测"出一个交叉点。可以直接检验这个交叉点是否出现。
- 第 3 步需要的计算量因此更小：交叉点检验只需要跑到 N≈45，不必到 50。
